# Русская локализация Tails on the Rocks

Начальный пакет русской локализации для Ren’Py. В `game/` лежат файлы-накладки: русские системные меню и игровые экраны, обучающий эпизод, основные подписи интерфейса и часть диалоговых сцен. Сюжетный пересказ и спойлеры не добавляются.

## Установка

1. Скопируйте содержимое папки `game/` из этого репозитория в папку `game/` установленной игры, объединив каталоги.
2. Запустите игру и выберите **Настройки → Язык → Русский**.
3. При первом запуске Ren’Py скомпилирует `.rpy`-файлы.

Локализация ещё не полная: в исходниках около 44 тысяч строк, поэтому остальные диалоги и тексты будут добавляться отдельными пакетами. Тон перевода следует оригиналу: в эротических сценах используется прямой, взрослый русский язык без смягчения смысла.
